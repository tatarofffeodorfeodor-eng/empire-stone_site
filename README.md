# Империя камня — сайт

Статический сайт (HTML/CSS/JS без сборки) для компании «Империя камня»: каталог, калькулятор, корзина, личный кабинет, админ-панель.

## Файлы
- `index.html` — разметка страницы
- `style.css`, `site.css` — стили
- `data.js` — каталог, цены, галерея
- `site.js` — логика сайта (роутинг, корзина, калькулятор, кабинет, админ-панель)

## Деплой
Сайт подключён к Netlify. При пуше в ветку `main` сайт должен обновляться автоматически после настройки интеграции Netlify ↔ GitHub.
